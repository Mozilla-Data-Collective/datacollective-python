# Contributing

This project is open-source: the code is public under the [Mozilla Public License 2.0](LICENSE), and you're welcome to view it and use it.

**However, this repository is not open to external code contributions (Pull Requests).**

## How you can help

- **Bug reports**: open a GitHub issue describing the problem, steps to reproduce, and your environment (Python version, package version, OS).
- **Feature requests**: open a GitHub issue describing the use case and desired behavior.
- **General feedback**: open a GitHub issue for any other enquiry.

We read and consider all issues, even though we can't accept code changes directly from the community. 
Maintainers will implement fixes and features internally as priorities allow.
